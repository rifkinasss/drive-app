# Cloud by NasLabs v1.0.0

This release records the baseline Cloud by NasLabs product before the v2.0.0 rebrand to Drive by NasLabs. It documents the capabilities present in the repository and does not claim a separate production deployment.

## Added

- Browser application frontend backed by a Laravel API and PostgreSQL.
- Session-based Laravel Sanctum SPA authentication with CSRF protection, login, logout, password reset, account setup, invitations, and email verification.
- Private file and folder management, upload, secure download and preview, browser search and sorting, recent files, starred files, Trash, restore, and permanent deletion.
- Storage quota accounting and storage maintenance workflows.
- Personal activity timeline and database notifications.
- Internal sharing and token-scoped public viewer links.
- Administrative user, quota, status, role, and system setting management.
- Branded API gateway, API documentation, and OpenAPI surfaces.

## Changed

- Established the initial Cloud by NasLabs product identity across the application, backend, documentation, and transactional email surfaces.
- Established the `/api/...` route structure used by the application without introducing a versioned `/api/v1` URL namespace.

## Security

- Private files are protected by ownership and sharing authorization checks.
- Public share access is scoped through share tokens and does not expose the private file browser.
- Authentication, session, invitation, verification, and password reset flows are handled by the backend.

## Compatibility

- Existing database migrations and internal storage identifiers remain the compatibility boundary for the application.
- Storage accounting remains part of file and folder lifecycle operations.

## Known Issues

- Public sharing is viewer-oriented; password protection, expiry controls, download limits, public upload, and public analytics are outside this baseline release.
- External invitation workflows and collaborative editing are outside this baseline release.
- Antivirus scanning and broader file-processing automation are outside this baseline release.

## Deferred

- Product rebranding beyond the Cloud by NasLabs baseline.
- Progressive Web App implementation.
- Broader storage-provider and infrastructure migrations.
