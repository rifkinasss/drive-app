# Drive by NasLabs v2.0.0

This release introduces the local source-code rebrand from Cloud by NasLabs to Drive by NasLabs.

## Added

- A release record for the Drive by NasLabs 2.0.0 identity update.
- Frontend application version `2.0.0` as the package version and build-time About fallback.
- Native online-only PWA metadata with standalone display, app icons, maskable icons, Apple touch icon support, and a working `/favicon.ico`.
- A network-loss banner that explains the online-only requirement and offers retry.
- An online-only Install Drive control with browser prompt handling and iOS Safari guidance.
- Authenticated notification preferences for shares, quota, and optional account/security alerts.
- A Recent Devices view backed by a user-scoped session metadata endpoint.
- Storage warning states based on real API quota percentages, including a full-storage Trash CTA.
- Public-share Copy link feedback and an Open in Drive CTA with a safe return path for signed-out users.
- A minimal service worker for install, activation, push display, and notification-click routing. It deliberately has no Cache Storage strategy.
- Online recovery feedback with safe stale-query refetching.
- User-scoped encrypted Web Push subscription storage and VAPID delivery configuration.
- User-initiated Push Notifications controls in Settings, respecting existing Shares, Quota, and Account & Security preferences.

## Changed

- Updated frontend identity, metadata, page title template, auth copy, settings/about copy, public share copy, errors, notifications, and sidebar branding.
- Updated backend `APP_NAME` and `API_VERSION` examples, API documentation title and description, backend landing page, documentation landing page, system-setting instance defaults, and transactional email subjects/content.
- Updated backend and frontend documentation examples to use the current Drive domains.
- Updated API and mail test expectations to match the new identity and domain examples.
- Added safe-area handling for standalone mobile display without changing the existing navigation or interaction model.

## Fixed

- Removed current user-facing references to the previous product name from the audited frontend and backend surfaces.
- Normalized network failures and common 401, 403, 404, 419, 500, and 503 API responses to actionable user-facing messages.
- Added preference-aware enforcement for optional internal-share and storage quota notifications.

## Security

- Added user-scoped read-only session activity metadata without exposing raw session identifiers, payloads, or cookies.
- Notification preference enforcement affects optional in-app share/quota notices only; authentication and transactional email behavior remains unchanged.
- Push payloads contain only a title, short body, safe internal URL, and notification type. Session cookies, tokens, file content, and public-share tokens are never placed in the worker or payload.

## Infrastructure

- Production deployment, DNS, Cloudflare, systemd, database, and physical storage were not modified. Domain changes in this release are documentation and source examples only.

## Compatibility

- Existing `/api/...` routes remain unchanged.
- Existing database names, migration filenames, storage variables, storage paths, `cloud:*` Artisan commands, and technical identifiers remain compatible.

## Known Issues

- Web Push delivery still depends on valid backend VAPID configuration and a supported browser permission state.
- Browser-specific install prompts and iOS Add to Home Screen behavior remain platform-dependent.
- Unsupported preview formats continue to show the intentional unavailable state.
- Internal technical names still contain `cloud` where they describe storage, commands, logs, disks, types, or compatibility surfaces.

## Deferred

- Service worker, offline caching, background sync, offline mutations, and offline private file access.
- WebDAV, resumable uploads, and native client synchronization.
- Offline file browsing, private previews/download caching, background sync, and offline mutation queues.
- Any broad internal namespace rename or storage migration.
